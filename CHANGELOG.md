# Changelog

## 0.1.0 (unreleased)

- Installers (bash and PowerShell) for rtk, code-review-graph, token-savior, graphify, context-mode, caveman, with dry-run mode
- Agents: `lean-main` (optional default), `lean-explorer`, `lean-reviewer`, `lean-coder`
- `dash` terminal dashboard (tabs, six coding themes, responsive tables, safe pass-through to the system `dash` shell)
- Token stack desktop app redesigned: tabs, themes, keyboard shortcuts, one shared view layer with `dash`; `--demo` sample data
- `token-report`; usage counted once per API request
- Shared-account view: per-device export and "who is using how much"
- `token-statusline` and `/handoff` for the growing-conversation cost
- `token-history` local searchable chat memory with guarded auto-recall and `/recall`
